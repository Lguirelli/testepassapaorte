# Páginas HTML da showcase

- `index.html` — Home
- `explorar.html` — Explorar
- `lugar.html` — Página de ponto turístico
- `parceiro.html` — Página comercial de parceiro
- `roteiro-criar.html` — Onboarding de criação do roteiro
- `roteiro.html` — Roteiro gerado / edição local
- `calendario.html` — Calendário Dia / Semana / Mês
- `passaporte.html` — Meu Passaporte
- `admin.html` — Admin operacional
- `404.html` — fallback de navegação

Todos usam `styles.css`, `app.js` e `assets/`.
