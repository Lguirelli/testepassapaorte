## Tipografia

A CSS usa os nomes definidos para a direção atual do projeto: `Druk Text Wide` para headings principais da Home, `Helvetica Neue` para UI/body da Home, `Arimo` para títulos internos e `Cormorant Garamond` para subtítulos/editorial. O repositório **não inclui arquivos de fontes comerciais**. Onde Druk/Helvetica Neue não estiverem licenciadas/instaladas, há fallback seguro.

## Paleta

A base permanece neutra: creme/off-white, bege acinzentado, taupe, grafite, carvão e preto profundo. Cores de nicho aparecem apenas em estados, rotas e carimbos.
