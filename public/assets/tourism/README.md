# Fotografias temporárias das páginas de turismo

Esta pasta contém **JPGs reais** usados como fallback local nas novas páginas de pontos turísticos. Eles não são vetores.

A página tenta primeiro a fotografia online indicada em `tourism-data.js`. Quando essa fotografia não está disponível, usa um destes JPGs locais. Onde o JPG não retrata o atrativo específico, a interface informa explicitamente que a imagem é ilustrativa.

Os arquivos locais vêm da biblioteca de fotos de banco já incorporada ao repositório e documentada em `../../ASSET_SOURCES_STOCK_IMAGES.md`.
