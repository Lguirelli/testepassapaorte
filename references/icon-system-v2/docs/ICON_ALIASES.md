# Aliases e reuso de glyphs

O registry mantém nomes semânticos distintos mesmo quando a geometria é reutilizada. Isso evita duplicação física sem perder o significado de cada contexto.

## Aliases detectados por geometria idêntica

- `lugar-custo` → `perfil-gastar-menos`
- `roteiro-caminhada` → `perfil-a-pe`
- `roteiro-tempo-livre` → `lugar-horario`
- `roteiro-clima-favoravel` → `clima-parcialmente-nublado`
- `qr-visita-registrada` → `perfil-nenhuma-necessidade`
- `mapa-pin-padrao` → `lugar-localizacao`
- `mapa-evento` → `calendario-atividade-planejada`
- `compartilhamento-visibilidade` → `lugar-ver-fotos`
- `parceiro-proximos-passos` → `passaporte-indice`
