# assets/stock

Esta pasta contém as **fotografias reais de banco** utilizadas nos cards e páginas internas do protótipo.

Observações:

- são imagens ilustrativas, não fotografias dos lugares fictícios do demo;
- os arquivos estão empacotados localmente para o ZIP não depender de CDNs externos;
- créditos e links de origem estão em `SOURCES.json` e `../../ASSET_SOURCES_STOCK_IMAGES.md`.
